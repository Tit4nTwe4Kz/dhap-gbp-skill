## v16.7 — Nov 5 2026 — funnel handoff: every finished run opens a pull request on Clikdata2/dhap-funnel-handoff (requested by Travis)
**Run routine step 10b (new):** once the seven files are built and every check passes, `run/scripts/funnel_handoff.py` puts the DHAP HTML, the Digital Health Alert HTML and an `info.json` (dealership name, slug, city and state, website, report ID, date) in a folder named `<name>-<MM-DD-YY>/` and opens a pull request with it on `Clikdata2/dhap-funnel-handoff`, so every run reaches the funnel team the same way, whoever runs it. It never overwrites: a folder already on `main` for that dealer and date, or a branch already sent, stops it. Needs the GitHub CLI signed in; Ask AI runs (no shell) skip it and say so. `--no-pr --stage DIR` builds the folder only.
